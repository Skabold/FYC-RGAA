# FYC-RGAA

Ce projet contient la **version non accessible et non corrigée** du site "Délices & Gourmandises". Ce dépôt sert de point de départ pour les travaux pratiques sur le RGAA (Référentiel Général d'Amélioration de l'Accessibilité).

## Organisation des travaux

Ce projet doit être amélioré progressivement du cours 3 au cours 8. À la fin de chaque cours, des corrections d'accessibilité doivent être apportées en fonction des thématiques abordées.

L'objectif final est de transformer cette version non conforme en un site respectant les critères du RGAA.
