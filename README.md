# FYC-RGAA

Ce projet est la correction du TP du FYC sur le RGAA.

Le site "Délices & Gourmandises" présenté ici est accessible car il respecte les critères du RGAA. Il a été développé comme exemple de mise en œuvre des bonnes pratiques d'accessibilité web.

Contrairement à la version trouvable sur la branche main du dépôt où se trouve ce projet. Cette version est en réalité la version corrigée et conforme aux normes d'accessibilité.

## Contenu du projet
- Site web culinaire avec articles, sondages et informations
- Mise en œuvre complète des critères RGAA
- Exemples de bonnes pratiques d'accessibilité.
